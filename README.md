# Подключение Redmi к GreenTaxi

Сборка для проверки рабочего Redmi с Android 15: GreenTaxi-Android.apk, версия 0.1.0. Приложение не записывает разговоры. Отправляются только принятые входящие звонки обычной SIM-карты; каждый создаёт карточку во входящих.

1. На телефоне скачайте APK и откройте его. Если Android предлагает, разрешите установку приложений из используемого браузера. После установки откройте Green Taxi.
2. Войдите в https://greentaxi.vercel.app/admin. В меню «პარამეტრები» (Настройки) найдите блок Android-телефонов. В поле «ტელეფონის სახელი» введите Redmi и нажмите «დაკავშირების კოდის შექმნა» (Создать код подключения). Скопируйте показанный код в приложение; это отдельный код устройства, не код активации администратора.
3. В приложении укажите адрес https://greentaxi.vercel.app без /api и вставьте код устройства. Нажмите «დაკავშირება» (Подключить). Этот шаг сохраняет параметры; он ещё не доказывает получение звонков сервером.
4. Нажмите «ნებართვების შემოწმება» (Проверить разрешения), предоставьте доступ к журналу звонков, телефону и уведомлениям, если Android предлагает. Все строки доступа должны показывать «ჩართულია» (Включено). Если журнал остаётся недоступным и Android не предлагает разрешение, остановитесь и проверьте установочные ограничения конкретного устройства; повторный запрос разрешения может не помочь.
5. Нажмите «მონიტორინგის ჩართვა» (Включить мониторинг). Должно появиться постоянное уведомление Green Taxi. В настройках Redmi для Green Taxi включите фоновый автозапуск и выберите режим батареи без ограничений, если эти параметры доступны.
6. После включения позвоните на SIM Redmi с другого номера, ответьте и завершите разговор. Во вкладке входящих админки должна появиться одна телефонная карточка. В настройках устройства обновится время последнего соединения только после отправки события. Старые звонки не импортируются.
7. Для проверки фона повторите звонок при заблокированном экране. Пропущенный и исходящий звонки не должны создавать карточки. Работу на этом Redmi можно считать проверенной после настоящих звонков, а не только после установки.

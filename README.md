# Green Taxi — обновление Redmi

[Скачать GreenTaxi-Android.apk](GreenTaxi-Android.apk), версия **0.2.0** (versionCode 3).

Установите APK поверх уже установленного Green Taxi, затем откройте приложение. Код подключения, очередь, разрешения и начало обработки сохраняются. Повторная привязка при обычном обновлении не нужна. Не удаляйте приложение и не очищайте его данные для установки обновления.

Включённый мониторинг возобновляется при открытии. Должно быть постоянное уведомление Green Taxi; настройки HyperOS «Автозапуск», «Без ограничений» и уведомления нужны как прежде. Кнопка «კავშირის შემოწმება» проверяет соединение с https://greentaxi.vercel.app.

В [админке](https://greentaxi.vercel.app/admin) откройте «შემოსული». Позвоните на SIM Redmi с другого номера и ответьте, оставив разговор открытым. Карточка должна появиться во время разговора. Грузинский номер виден как `568 69 48 79`, без +995; для знакомого номера сразу показываются сохранённые имя, адрес в Гори и действующая точка Тбилиси. Дату, время и места для поездки выбирает оператор заново.

Оформите заказ из карточки во время разговора. После завершения обновляется та же карточка; созданный заказ сохраняет выбранные данные. Пропущенные, отклонённые и исходящие звонки не создают карточки. Приложение не записывает разговор и не получает контакты.

Ранняя отправка обычных SIM-звонков доступна на Android 12 и новее. Ожидающие/неоднозначные звонки и перерывы наблюдения могут обрабатываться после завершения по журналу. При отсутствии интернета события ждут в сохранённой очереди. Новую раннюю отправку нужно проверить на рабочем Redmi; сборка и серверные проверки сами не подтверждают физическую доставку.

Если нужна новая привязка: в «პარამეტრები» админки создайте код устройства и сохраните его в приложении вместе с корневым HTTPS-адресом сайта без /api. Код не сообщайте в чат. Эта процедура не требуется для сохранённой рабочей привязки.

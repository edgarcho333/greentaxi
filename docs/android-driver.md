# Приложение GreenTaxi Driver

Кабинет доступен двумя способами:

- Android APK: `https://green-taxi.ge/downloads/GreenTaxi-Driver-Android.apk`.
- Через браузер: `https://green-taxi.ge/driver`.

Оба варианта используют действующий сайт и существующую базу Neon. Для работы нужен интернет. Номера телефонов администратор задаёт в «პარამეტრები» рядом с водителями. Вход выполняется по сохранённому номеру без пароля и SMS; форматы с `+995` и без него равнозначны. Изменение или удаление номера закрывает прежние сеансы соответствующего водителя.

## Установка и работа

1. Откройте ссылку APK на телефоне и скачайте файл. Ссылка есть также под формой входа водителя на сайте.
2. Откройте скачанный файл. При запросе Android разрешите установку из использованного браузера или файлового менеджера.
3. Запустите **GreenTaxi Driver** и введите свой номер, сохранённый администратором.
4. Переключайте «დღეს / ხვალ», отмечайте «ვმუშაობ» либо «არ ვმუშაობ» и выбирайте час над списком заказов. Нажатие номера пассажира открывает стандартный набор телефона; звонок запускается самим водителем.

Один выбранный день управляет и участием, и списком заказов. Обычные водители назначенного рейса видят его общий список пассажирских заказов и посылок, исключая чужие заказы целой машины. На часу исполнения «მთლიანი მანქანა» водитель видит только свои такие заказы, а на остальных назначенных часах — общий список соответствующего рейса. Один водитель может быть назначен на несколько часов одного дня; они доступны отдельными кнопками, включая пока пустые рейсы. Отказ от рабочего дня не отменяет бронирования целой машины: в этом случае приложение предлагает обратиться к администратору.

Пассажиры, добавленные вместе в одном оформлении на одинаковые дату, время и направление,
показаны общим блоком **«ერთ მანქანაში»** — «В одной машине». В заголовке указано
общее число мест, а внутри каждая точка посадки сохраняет собственные адрес,
телефон, места и услуги. Счётчик заказов учитывает такие блоки, счётчик мест —
все входящие в них активные записи ровно один раз. Если группа не помещается
в машину водителя, показано указание связаться с оператором; приложение не делит
её автоматически между машинами.

У перенесённого на другой рейс или отменённого пассажира сохраняется отдельная
запись; он больше не входит в общий блок прежнего рейса. Общего номера звонящего
недостаточно для объединения независимых заказов. Скрытые водителю заказы целой
машины, их телефоны и количество в блок не попадают. Пометка совместной поездки
не меняет действующие назначения водителей на часы.

Это обновление сайта работает и в APK без его переустановки. Чтобы загрузить
новый интерфейс в уже открытом кабинете, обновите страницу браузера или закройте
приложение водителя и откройте снова.

## Android-проект

Модуль `android/driver` и пакет `ge.greentaxi.driver` отделены от существующего приложения `android/app`, которое передаёт SIM-звонки в очередь оператора. Обновления водителя не заменяют приложение звонков и не используют его закрытый ключ.

Приложение открывает HTTPS-кабинет `green-taxi.ge/driver`. Оно сохраняет собственный сеанс входа между запусками; сеанс браузера на телефоне независим. Учётная запись и данные при этом общие. Нужны только сетевые возможности: приложение не читает контакты, SMS или журнал звонков. Доступ к камере, микрофону и местоположению не требуется. При отсутствии сети показана кнопка повторной загрузки.

## Повторная сборка

Инструменты подготавливаются существующим `scripts/setup-android.sh`. Используйте `python3 scripts/build-android-driver.py` для сборки и проверки release APK. Результат копируется в `public/downloads/GreenTaxi-Driver-Android.apk`; метаданные версии, размера, SHA256 и сертификата находятся в `public/downloads/driver-release.json`.

Закрытый ключ подписи водителя хранится вне Git в приватном каталоге инструментов среды. Для обновления уже установленного приложения требуется тот же ключ. Сохраните приватный каталог подписи в резервной копии среды; не публикуйте его вместе с APK. При утрате ключа восстановления существующей подписи из APK нет.

Перед публикацией обновления повышайте `versionCode`, собирайте APK, проверяйте подпись и lint, затем собирайте веб-приложение. Публикуйте проверенный коммит через существующий `scripts/deployment/vercel.mjs --update-existing`. На основном домене проверьте загрузку APK, его SHA256 и вход `/driver`; тестовые заказы и новые номера водителей в production для такой проверки не нужны.

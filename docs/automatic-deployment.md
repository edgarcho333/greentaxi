# Автоматическое подключение Vercel и Neon

Сценарий `scripts/deployment/index.mjs` создаёт проекты, получает pooled-подключение Neon, передаёт его в production-переменную Vercel и публикует исходники ветки `main`. Ключи и строка базы остаются в памяти процесса. В журнал попадают только этапы работы, идентификаторы проектов и адрес сайта.

Если секреты среды Codex доступны только во время её настройки, запускайте сценарий из **Setup script**, а не из уже работающей задачи агента.

Добавьте три секрета в среду:

| Имя | Значение |
| --- | --- |
| `VERCEL_TOKEN` | API-токен нужного аккаунта/команды Vercel |
| `NEON_API_KEY` | API-ключ Neon с правом создания проекта |
| `ADMIN_SETUP_TOKEN` | Собственный случайный код активации первого сотрудника, не менее 32 символов; сохраните его в менеджере паролей |

После получения свежей ветки `main` запуск из Setup script:

```sh
cd /workspace/greentaxi
node --use-env-proxy scripts/deployment/index.mjs --deploy
```

Без `--deploy` сценарий выводит план и не выполняет сетевых запросов. Если отсутствует любой из трёх секретов, создание ресурсов не начинается. При нескольких доступных аккаунтах сценарий попросит указать `VERCEL_TEAM_ID` или `NEON_ORG_ID` в обычных переменных среды; это идентификаторы, не пароли.

После готовности deployment сценарий проверяет публичное API и первоначальное расписание. Успешный результат без секретов сохраняется в `/workspace/.greentaxi-tools/deployment/result.json`. Он содержит адрес сайта и идентификаторы ресурсов; повторный запуск для того же коммита использует этот результат.

Откройте опубликованный адрес с путём `/admin`, введите свой `ADMIN_SETUP_TOKEN` и выберите логин и пароль сотрудника. Затем удалите `ADMIN_SETUP_TOKEN` из production-переменных Vercel и выполните Redeploy. Ключи провайдеров не используются как пароли панели.

Публикация через загрузку исходников не настраивает автоматическое обновление при каждом Git push. Такое обновление можно отдельно подключить через Git-интеграцию Vercel с веткой `main`. Подробные настройки сайта и проверка телефона описаны в [инструкции Vercel + Neon](deployment-vercel-neon.md).

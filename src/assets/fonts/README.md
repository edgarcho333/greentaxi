# GreenTaxi fonts

The owner supplied these files for the website on 7 October 2026:

- `DachiTheLynx-Regular.otf`: the Regular face from `Dachi The Lynx [typeface.ge].zip`, used for headings. The font's internal family name is **Dachi The Lynx**.
- `FiraGO-400.woff2`, `FiraGO-500.woff2`, `FiraGO-600.woff2`, `FiraGO-700.woff2` and `FiraGO-800.woff2`: the original normal-style webfonts from `firago.zip`, used for body text, controls, tables and numbers. Although the supplied filenames contain `latin`, these faces also cover Georgian Mkhedruli and Cyrillic.

The files are hosted locally and retain their original bytes. FiraGO's bundled SIL Open Font License is preserved in [FiraGO-LICENSE.txt](FiraGO-LICENSE.txt). Shared font declarations are in `src/fonts.css`; the print document and standalone HTML preview use the same fonts.
